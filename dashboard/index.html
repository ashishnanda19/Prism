Prism is a from-scratch C++17 deep-packet-inspection engine. This dashboard drives every binary and library primitive in the project so you can run and inspect each feature. The backend shells out to build/bin/prism* on this machine.

Configure & build the project, and run the doctest suite.

Sanitizers & fuzzers

Run from a shell (they need a dedicated build dir):

cmake -S . -B build-asan -DCMAKE_CXX_COMPILER=clang++ -DPRISM_SANITIZE=address,undefined cmake --build build-asan -j && ctest --test-dir build-asan --output-on-failure cmake -S . -B build-fuzz -DPRISM_BUILD_FUZZERS=ON -DPRISM_BUILD_TESTS=OFF -DPRISM_SANITIZE=address,undefined cmake --build build-fuzz -j && python3 fuzz/seed_corpus.py ./build-fuzz/bin/fuzz_tls_fingerprint -max_total_time=60 fuzz/corpus/tls_fingerprint
